Fish Dock

Dock magnification as recovered from macOS 27.0 Dock.app, drawn with the same arithmetic. Move the pointer along the dock. Set your real Dock to the same tile and magnified sizes and compare.

What the Dock computes

fishSize    = 3 · tileSize
realScale   = fish · (largeSize − tileSize) / 2 ÷ sin(π · tileSize / (4 · fishSize))
S(d)        = −1 if d ≤ −fishSize,  +1 if d ≥ fishSize,  sin(π · d / (2 · fishSize)) otherwise
D(x)        = x + realScale · S(x − fishCenter)
tile extent = [D(left edge), D(right edge)]
ramp        = floor(42 · ln(|Δsize| / 2 + 1) + 1) ms, linear

Every tile keeps its unmagnified width in the layout; what you see is each edge displaced through D. Tiles more than three tile widths from the pointer are pushed aside without changing size. The grow and shrink ramps run when the pointer enters and leaves the dock, timed as the real Dock times them. Bar padding, shadows and icon art are not part of the recovered model.
